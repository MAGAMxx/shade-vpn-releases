SHADE - приложение для подключения к вашим серверам через ядро Xray.

Доступно для Android, Windows и Linux. Версия для iOS готовится.

Возможности

  • Подписки по ссылке и QR-коду, несколько подписок сразу
  • Протоколы VLESS (Reality), VMess, Trojan, Shadowsocks
  • Российские сайты и приложения напрямую, без туннеля
  • Режим «Запрет» на Windows и Linux: YouTube и Discord без VPN-сервера
  • Проверка пинга: через прокси, TCP, ICMP
  • Kill switch и постоянный VPN средствами Android

SHADE не собирает ваши данные и не хранит историю соединений. Всё, что вы настраиваете, остаётся на устройстве.

SHADE не предоставляет серверы. Приложение работает только с подписками и серверами, которые вы добавили сами. Используйте его в соответствии с законами вашей страны.
